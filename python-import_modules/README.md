# Python - import & modules

Basics of importing modules, `sys.argv`, and making scripts safe to import
with `if __name__ == "__main__":`.

| File | Description |
|------|-------------|
| `0-add.py` | Imports `add` from `add_0.py` and prints `1 + 2 = 3` |
| `1-calculation.py` | Imports `add`, `sub`, `mul`, `div` from `calculator_1.py` |
| `2-args.py` | Prints the number of arguments and the list of arguments |
| `3-infinite_add.py` | Prints the sum of all arguments |
| `4-hidden_discovery.py` | Prints the names defined in `hidden_4.pyc`, sorted |
| `5-variable_load.py` | Imports `a` from `variable_load_5.py` and prints it |
